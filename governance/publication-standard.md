# Publication Standard (GitHub, Kaggle, GitHub Pages)

1. **Mandatory Human Approval:** No dataset, policy report, or dashboard update may be published externally without explicit Research Director approval.
2. **Kaggle Release Checklist:** Each Kaggle dataset must include a description, data dictionary, source attribution, reporting period, methodology, license assessment, privacy assessment, limitations, version, and update date.
3. **No Unverified Figures on Public Dashboards:** Never display synthetic test numbers or unvalidated estimates as empirical facts.
4. **Governance Auditor Sign-Off:** Every release requires a passing `validation.py`, passing `privacy_review.py`, and Governance Auditor checklist sign-off.
